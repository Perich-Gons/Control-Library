# Control-Library

Biblioteca pública de resoluciones reutilizables para instalaciones de Control.

Contiene propuestas y resoluciones revisables: pregunta, solución, compatibilidad,
fuentes, límites y señales comunitarias. No contiene código de Control, rutas de
equipos, credenciales, tokens, usuarios ni registros de terminal.

Las contribuciones se realizan mediante Pull Request desde un fork. Consulta
[PROTOCOL.md](PROTOCOL.md) y [CONTRIBUTING.md](CONTRIBUTING.md).
